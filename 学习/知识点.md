rtc在always on 模块，一直处于上电状态，rtc本身不掉电。但rtc里面有掉电模式，把该寄存器配成1后，alarm信号拉高后会让awake信号拉高告诉对方我现在要唤醒其他模块了。可以给别的模块提供唤醒模式，让别的模块从唤醒模式恢复。

覆盖率：
功能覆盖率。
代码覆盖率：行覆盖率、分支覆盖率、条件覆盖率、翻转覆盖率、FSM覆盖率。

每次 testcase 仿真各自产生一份 coverage database，然后用覆盖率工具把这些 database 合并，统计所有测试共同覆盖到的 RTL 行、分支、条件、toggle、FSM、功能 bin 的并集。

定向测试和随机测试：
定向测试是确定的去打一个点，例如把地址和数据都固定在一个值
随机测试可以给地址或数据一个范围，或者不同范围一个不同的权重
场景定向+数据随机：
例如：

```
仅仅：
Feb 29 闰年进位
```

很适合：

```
定向 testcase
```

因为这是非常明确的 corner case。

而：

```
很多月末日期组合覆盖不足
```

则更适合：

```
修改 constraint

day dist {
    28 := 20,
    29 := 20,
    30 := 20,
    31 := 20,
    [1:27] := 20
};
```

让随机更容易碰到月末。
