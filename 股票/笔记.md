### 规则一：任何中线票，买入前必须写“失效条件”

以后你不能只写：

> 我看好，目标价多少。

你要写：

```
我为什么买？我预计什么时候验证？如果我错了，会出现什么信号？出现什么情况减仓？出现什么情况清仓？最大允许亏损或回撤是多少？
```

没有这六条，不允许买。

---

### 规则二：盘中恐慌时，不允许一次性清仓

如果你原本是中线逻辑，盘中突然大跌，最多先做防守动作，比如：

```
跌破心理承受位：减1/3；板块继续杀跌：再减1/3；收盘仍无法修复或次日继续走弱：再决定是否清仓。
```

这样做的好处是：  
你既不会完全死扛，也不会因为一次恐慌把自己洗出去。

---

### 规则三：卖出后一小时内禁止买入新票

这是你现在最需要的一条。

尤其是这种情况：

```
刚卖出；马上后悔；看见另一个票反弹；想立刻买回来；觉得不买就错过。
```

这种时候，必须强制空仓冷静。

你可以给自己写一条铁律：

> **情绪化卖出后，60分钟内不允许开新仓。尾盘最后30分钟卖出后，当天不允许再买。**

这条规则会直接阻断“恐慌卖出—后悔追买”的连锁反应。

---

### 规则四：论坛只能用于收集信息，不能用于做决定

你今天狂刷论坛，看到别人说跌破趋势、开始止盈，然后你被影响了。

以后你可以看论坛，但只能记录三类信息：

```
1. 有无公司公告；2. 有无行业突发；3. 有无客观数据。
```

至于别人说“趋势坏了”“赶紧跑”“明天跌停”“主力出货”，这些都不能成为你的交易依据。

论坛的最大问题是：  
上涨时它会让你更贪，下跌时它会让你更怕。
